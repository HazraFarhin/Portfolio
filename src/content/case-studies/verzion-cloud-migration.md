## Tools Used

- Figma
- FigJam
- Miro
- Notion

## Outcome & Impact

- Stakeholders approved the redesigned migration console for the next release cycle
- Simplified the primary migration flow into a smaller number of clearer steps
- Reduced the amount of supporting documentation IT teams needed to reference mid-task

## The Challenge

- Enterprise IT teams found the existing migration process difficult to track across multiple stages
- Critical status information was scattered across several screens, increasing the risk of missed steps
- The tool's technical language didn't match how IT teams actually described their own workflows

> IT teams didn't need more information about the migration -- they needed to stop hunting for it across five different screens.

## Process

### 1. Discovery & Research

Interviewed IT administrators and reviewed support tickets to understand where migrations were stalling or causing confusion.

### 2. Define

Mapped the end-to-end migration journey and framed the core problem around visibility and trust at each stage.

### 3. Ideate & Wireframe

Sketched several structures for a unified migration dashboard before settling on a single-flow, stage-based layout.

### 4. Design & Prototype

Designed high-fidelity screens for the migration console, including status indicators and in-progress states for each stage.

### 5. Test & Iterate

Tested the prototype with IT administrators and refined the stage indicators and terminology based on their feedback.

## Solution

The redesigned console consolidates migration status into a single, stage-based view, so IT teams can see where a migration stands and what's next without leaving the main screen. Terminology throughout the flow was rewritten to match how administrators actually talk about the process.

## Learnings & Reflections

The biggest surprise was how much trust depended on visible status, not just accurate status -- an early version had correct data buried too deep to reassure anxious administrators mid-migration. Next time, I'd prioritize surfacing state earlier in the design process instead of treating it as a polish pass.
