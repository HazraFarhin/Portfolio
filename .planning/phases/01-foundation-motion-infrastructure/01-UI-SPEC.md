## Spacing Scale

Declared values (must be multiples of 4) — standard 8-point scale, used in place of Axisform's non-8pt 20px base (D-02: adapt, don't extract byte-for-byte):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps, inline padding |
| sm | 8px | Compact element spacing |
| md | 16px | Default element spacing |
| lg | 24px | Section padding, glass card internal padding |
| xl | 32px | Layout gaps, reveal-animation travel distance (`useScrollReveal` default y-offset) |
| 2xl | 48px | Major section breaks |
| 3xl | 64px | Page-level spacing (Hero top/bottom padding on desktop) |

Exceptions:
- 44px minimum tap target for icon-only interactive controls (accessibility floor, not a spacing token — applies to any icon-only button introduced later).
- Axisform's literal 20px base unit and 24px section padding are intentionally NOT carried over 1:1; 24px already lands on this scale (`lg`) and is kept, 20px is dropped in favor of `md`(16)/`lg`(24) per D-02.

## Typography

| Role | Size | Weight | Line Height |
|------|------|--------|-------------|
| Label | 14px | 400 (Regular) | 1.4 |
| Body | 18px | 400 (Regular) | 1.6 |
| Heading | 40px | 800 (Extrabold) | 1.15 |
| Display | 88px (clamp to ~48px on mobile, e.g. `clamp(48px, 8vw, 88px)`) | 800 (Extrabold) | 1.0 |

Exactly 2 weights declared (400, 800) per contract discipline — Axisform's reference uses 400/600/800/900; this phase collapses that to two for restraint, using 800 to carry the "oversized editorial, negative letter-spacing" effect D-07 asks for without adding a third/fourth weight.

**Role assignment for Phase 1's Hero (D-05):**
- Eyebrow (`Hazra Farhin · UX/UI Designer`) → **Label** role, uppercase, tracked (`letter-spacing: 0.14em`, matching Axisform's label convention).
- Hero statement (the ~400-character positioning paragraph) → **Body** role at 18px/1.6, NOT Display/Heading — it is long-form paragraph copy, not a short punchy wordmark; oversizing it to Display tier would hurt readability and contradicts "clarity over decoration" (core value). Heading/Display tiers remain reserved for short strings in later phases (e.g. Phase 3's "Studio Method" oversized action words, section headings).
- Secondary meta card copy (glass panel) → **Label**-or-**Body** mixed: descriptive sentence at Body 18px, the `Remote · CET to GST overlap · Available for new work` status line at Label 14px/uppercase-optional.
- Primary CTA button label → Label-weight styling inside `Button` component (not a raw Typography role; button owns its own internal text treatment at ~16px/600-equivalent visual weight achieved via the 800 weight token at smaller size, or 400 with letter-spacing — executor's discretion within the 2-weight budget).

Heading (40px/800) and Display (88px/800) are locked now per D-01 but have no consumer inside Phase 1's Hero-only scope — they exist so Phase 2 (case-study page titles) and Phase 3 (section headings, oversized action words) consume the same tokens without a second negotiation.

## Color

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `#0B0C0A` | Page background (near-black, warm-neutral undertone — adapted from Axisform's `#060706` per D-02, not extracted byte-for-byte) |
| Secondary (30%) | `#16171A` | Glass card / panel surfaces, future nav bar background |
| Accent (10%) | `#FF6A33` | See reserved-for list below (adapted from Axisform's `#ff5a1f`) |
| Destructive | `#E5484D` | Not used in Phase 1 (no forms/destructive actions exist yet) — reserved for Phase 4 contact-form validation errors so the token exists before it's needed |

Supplementary tokens (not part of the 60/30/10 split but required for a dark UI and not optional to leave undeclared):

| Role | Value | Usage |
|------|-------|-------|
| Foreground (text) | `#F2EFE6` | Primary text on dark surfaces (adapted from Axisform's `#f3f0e8`) |
| Muted foreground | `rgba(242, 239, 230, 0.58)` | Secondary/supporting text (meta card descriptive line, captions) |
| Line / border | `rgba(242, 239, 230, 0.10)` | 1px glass-card borders, hairline dividers |

**Accent reserved for (explicit list — never "all interactive elements"):**
- Primary CTA button (`View Selected Work →`) background/border, both idle and hover states
- Availability status indicator (the small dot implied by "Available for new work" in the meta card copy)
- Link/nav hover or active-underline state (groundwork for Phase 3's nav; no nav ships in Phase 1)
- Focus ring color for keyboard-focused interactive elements (doubles as the accessibility focus indicator, satisfying part of QUAL-04's "visible focus states" ahead of Phase 5)

Nothing else uses the accent color this phase — body text, card borders, and backgrounds stay within dominant/secondary/foreground tokens.

**Surface & Elevation Notes** (glass-morphism, required by D-07, not otherwise captured in the table above):
- Glass card: `backdrop-filter: blur(16px)`, background `rgba(22, 23, 26, 0.55)` (Secondary token at reduced opacity, not solid), 1px border using the Line token, `border-radius: 24px`, drop shadow `0 24px 80px rgba(0,0,0,0.5)`.
- Button (primary): pill radius (`999px`), 1px border in accent at low opacity idle → full accent on hover, subtle lift (`translateY(-2px)`) on hover — reduced-motion-safe (no lift/parallax when `prefers-reduced-motion` is set, hover color change still allowed since it's not motion).
