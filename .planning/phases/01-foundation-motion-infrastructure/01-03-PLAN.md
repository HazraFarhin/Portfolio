## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| OS accessibility setting -> browser `matchMedia` -> React Context | The one channel through which the reduced-motion preference crosses into application state; a bug here silently un-gates motion for users who opted out |
| GSAP `ticker` (single rAF loop) -> Lenis `.raf()` -> `ScrollTrigger.update` | The scroll-sync loop; a leaked/duplicated ticker registration degrades performance over a session, not a security boundary but a real reliability risk |
